## 1. Introduction

The Flutter To-Do List Application is a simple task management mobile application developed using Flutter and Dart. It helps users organize their daily activities by adding tasks, marking them as completed, viewing pending tasks, and deleting tasks.

The application uses local storage to save tasks on the device, allowing users to access their saved tasks even after restarting the application.

## 2. Objectives

- To develop a simple and user-friendly task management application.
- To understand Flutter widgets and Dart programming.
- To implement adding, completing, and deleting tasks.
- To filter tasks based on their completion status.
- To store task information locally using SharedPreferences.
- To understand version control using Git and GitHub.

## 4. Features

- **Add Tasks:** Create new tasks using the text input field.
- **Complete Tasks:** Mark tasks as completed using checkboxes.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Filter Tasks:** View all, pending, or completed tasks.
- **Local Storage:** Save tasks on the device using SharedPreferences.
- **Simple User Interface:** Navigate and manage tasks easily.

## 6. Installation and Execution

### Prerequisites

- Flutter SDK
- Dart SDK (included with Flutter)
- Visual Studio Code
- Android Emulator or a compatible device

### Steps to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/flutter-todo-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd flutter-todo-app
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

Replace `YOUR_USERNAME` with the GitHub account that hosts the repository.
